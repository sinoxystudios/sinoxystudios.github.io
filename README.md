# Sinoxy Studios

Responsive studio website using the supplied starfield background and Sinoxy black-hole banner.

## Publish on GitHub Pages
1. Create a repository (for a user site, name it `sinoxy-studios.github.io`).
2. Upload `index.html` and the complete `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Your site will publish at `https://sinoxy-studios.github.io/` (for the matching user-site repository).

Keep the `assets` folder beside `index.html`; the page references both images from that folder.
